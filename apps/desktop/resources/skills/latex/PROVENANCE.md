# Provenance

The `scripts/` and `tests/` in this package are adapted from the bundled
"latex" plugin of the OpenAI Codex desktop application (license:
Proprietary). Adaptations: the Tectonic lookup prefers `PI_TECTONIC_PATH`
(keeping `CODEX_TECTONIC_PATH` as a compatibility fallback), the managed
TeX Live runtime moved to `~/.cache/pi-desktop-runtimes/pi-texlive`, and
product wording was re-targeted to PI-Desktop. Distribution terms for this
proprietary-derived code are an open product decision; see the task notes.
