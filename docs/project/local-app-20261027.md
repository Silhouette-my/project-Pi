## Contents and source

This local macOS application combines the session-backed Workflow changes and
the archived-conversation manager under Settings → General. The archive manager
supports title/project search, opening a conversation without restoring it, and
restoring it to navigation while retaining its metadata.

## Application

`apps/desktop/release/mac-arm64/PI-Desktop.app`.

Version: `0.21.0-beta.4`, macOS arm64. This is a local package without Developer ID
signing or notarization, not a published release. The bundle contains the release
Rust Host, bundled Agent sidecar, renderer, preload, and shipped plugin resources.

Build command (reuses the existing linked dependency store and Cargo target):

```bash
CSC_IDENTITY_AUTO_DISCOVERY=false \
npm_config_verify_deps_before_run=false \
npm_config_verifyDepsBeforeRun=false \
pnpm --config.verifyDepsBeforeRun=false --filter @pi-desktop/desktop run pack
```

Use `run pack`: bare `pnpm pack` creates a package tarball rather than invoking
the application packaging script.
